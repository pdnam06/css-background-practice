# Thực hành màu nền và ảnh nền CSS

Trang gồm tiêu đề theo đề bài, đoạn mô tả và khối div chứa nội dung quan trọng.

- body dùng background-color: #edf5f2.
- .important-content dùng background-image với ảnh núi SVG cục bộ.
- Một lớp gradient tối giúp chữ trắng dễ đọc.
- background-size: cover, background-position: center và background-repeat: no-repeat điều chỉnh ảnh nền.
- Flexbox căn giữa nội dung theo cả hai chiều; text-align: center căn giữa chữ.

Mở index.html bằng trình duyệt. Không cần cài thư viện hoặc kết nối Internet.

## Các tệp
- index.html: nội dung trang.
- style.css: định dạng.
- images/mountain-background.svg: ảnh nền được tạo cho bài thực hành.
- desktop.png, mobile.png: ảnh kết quả.
